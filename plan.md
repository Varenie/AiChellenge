# План реализации подсчета токенов и суммаризации

**Цель:** Добавить подсчет токенов для запросов и ответов, а также реализовать механизм суммаризации
для длинных запросов, чтобы оптимизировать расход ресурсов и улучшить пользовательский опыт.

**Архитектура:** Будем следовать принципам Clean Architecture и MVI, которые уже заложены в проекте.
